# Музыка (OST)

Чтобы добавить трек, положи `.mp3`, `.ogg` или `.wav` файл в нужную папку — он подхватится
автоматически при следующем запуске игры, код трогать не нужно.

В отличие от `assets/sounds/`, треки не грузятся целиком в память: `MusicManager` стримит их
с диска через `pygame.mixer.music` — это единственный поток музыки за раз (не полифония, как
у коротких звуков), что и нужно для длинных OST-композиций.

Если в папке несколько файлов, при переключении на эту категорию выбирается случайный трек,
он проигрывается в цикле с плавным fade-in (`MusicManager.FADE_IN_MS`). Повторный вызов той же
категории ничего не делает — трек не перезапускается, пока категория не сменится.

## Папки

- `menu/` — фоновая музыка главного меню, запускается при старте приложения
- `gameplay/` — фоновая музыка во время игры, запускается при старте новой игры

Чтобы добавить новую категорию (например, отдельный трек на победу/поражение), заведи новую
папку с тем же именем, что и категория, и вызови `music_manager.play_category("имя_папки")`
в нужном месте UI-кода.
