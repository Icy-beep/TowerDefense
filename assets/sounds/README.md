# Звуки

Чтобы добавить звук, положи `.wav`, `.ogg` или `.mp3` файл в нужную папку — он подхватится
автоматически при следующем запуске игры, код трогать не нужно.

Если в папке несколько файлов, при каждом проигрывании выбирается случайный — удобно
для вариаций одного и того же звука (например, три разных выстрела лазера).

Звуки, привязанные к точке на карте (выстрелы, взрыв, постройка, смерть врага, удар по базе),
приглушаются вне текущего вида камеры и полностью пропадают далеко за его пределами.

## Папки

- `laser_fire/` — выстрел лазерной башни
- `bullet_fire/` — выстрел пулемётной башни
- `mortar_fire/` — выстрел (запуск снаряда) миномётной башни
- `mortar_explosion/` — взрыв миномётного снаряда при падении, отдельно от выстрела
- `tower_placed/` — постройка башни
- `enemy_death/` — уничтожение врага
- `base_hit/` — враг дошёл до базы
- `victory/` — победа
- `defeat/` — поражение

Чтобы добавить новое событие (например, апгрейд башни), заведи новую папку с тем же именем,
что и ключ события, и вызови `sound_manager.play("имя_папки")` в нужном месте UI-кода.
