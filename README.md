# Tower Defense

Проект по ООП: Tower Defense на Python + pygame.
По игровому полю движутся волны противников, игрок размещает
оборонительные башни, чтобы не допустить прорыва врагов к базе.

## Возможности

- Главное меню (Начать игру / Выйти)
- 3 типа башен (Laser / Bullet / Mortar) с апгрейдом и разными типами урона
- Типов противников немало, у них разная броня (допишу типы потом)
- ~~Случайное число волн и~~ случайный состав противников при старте игры, волн теперь нет
- Система ресурсов, победа/поражение, задания.
- A*-навигация врагов по сетке, свободная камера с зумом, привязка построек к сетке
- Параметры башен/противников читаются из data/config/*.json

## Установка

PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

cmd.exe:

```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

Либо через setuptools (устанавливает проект как пакет):

```powershell
pip install -e ".[dev]"
```

## Запуск

```powershell
python main.py
```

Управление: `1`/`2`/`3` - выбрать башню, ЛКМ - поставить/выбрать,
ПКМ - снять выбор, `U` - улучшить башню, `SPACE` - начать волну,
`WASD`/стрелки - камера, колесо мыши - зум, `P` - пауза, `R` - камеру на базу.

## Тесты

```powershell
pytest tests/
```

## Сборка в исполняемый файл

```powershell
pyinstaller main.spec
```

## Структура проекта

```
src/
├── core/          # доменная модель: сессия, карта, состояние игры, навигация, камера, контроллеры режимов
├── entities/       # игровые сущности: башни, противники, снаряды
├── systems/        # игровые системы: волны, ресурсы
├── factories/       # фабрики башен/противников (читают параметры через ConfigLoader)
├── enums/           # все перечисления проекта
├── config/           # ConfigLoader - читает data/config/*.json
├── ui/              # UI-слой (pygame): меню, окно, отрисовка карты, HUD, экран победы/поражения
├── skills/          # заготовка под навыки Operator-режима (план)
├── events/          # заготовка под событийную систему (план)
└── save_load/        # заготовка под сохранения (план)

data/
└── config/           # towers.json / enemies.json - параметры без пересборки кода

docs/
├── diagrams/         # UML-диаграммы (use case, классы, последовательности)
├── GD_tower_defense.docx
└── ООП_8_Проект_Tower_Defense.pdf   # ТЗ

tests/                # модульные тесты ключевой игровой логики
```
